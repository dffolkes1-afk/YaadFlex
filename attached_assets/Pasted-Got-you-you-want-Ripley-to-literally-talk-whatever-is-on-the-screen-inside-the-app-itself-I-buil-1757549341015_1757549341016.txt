What it does

Reads live content in a window marked with data-tts="auto" (auto re-reads when text changes).

Reads focused fields (inputs, textareas, contenteditable).

Play / Pause / Resume / Stop controls, voice/rate/pitch/volume.

Tries to pick an English voice automatically (you can choose others).

Zero server cost (uses the browser’s Web Speech API). Falls back gracefully if not supported.


How to use (super simple)

1. Drop both files into your project.


2. Include the script in your page/app shell:

<script src="./ripley-tts.js"></script>


3. Tag the window you want read automatically:

<div data-tts="auto" id="ripley-window">…your dynamic text…</div>


4. (Optional) Mount built-in controls:

<div id="controls"></div>
<script>RipleyTTS.mountControls(document.getElementById('controls'));</script>


5. Speak anything on demand:

RipleyTTS.say("Ride arriving in 2 minutes", { interrupt: true });



React / Next.js quick hook (bonus)

If Ripley is React:

import { useEffect, useRef } from "react";

export function useRipleyTTS(autoSelector='[data-tts="auto"]') {
  const inited = useRef(false);
  useEffect(() => {
    if (!inited.current && window.RipleyTTS) {
      window.RipleyTTS.init?.();
      inited.current = true;
    }
  }, []);
  return {
    say: (text, opts) => window.RipleyTTS?.say(text, opts),
    stop: () => window.RipleyTTS?.stop(),
  };
}

Then:

const { say } = useRipleyTTS();
useEffect(() => { say("Welcome to YaadFlex!"); }, []);
