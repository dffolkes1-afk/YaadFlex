You’re close. Here’s the clean path so you can (1) test safely, (2) protect the brand, and (3) make the site feel like an app on phones.

1) Protect it before public testing (fast)

Grab domains: yardflex.app, yardflex.com (or closest available).

Reserve the business name: Companies Office of Jamaica (COJ) name reservation → then register YardFlex Ltd.

Lock the brand: file a trademark for “YardFlex” (name + logo) in Jamaica first (you can expand later).

Private beta gate: invite codes / password + a simple NDA/consent wall on first login.


> You don’t need government approval to show a website, but the above stops people from “taking” your name.



2) Test first, then open the webpage

Run a private beta at a secret URL (e.g., beta.yardflex.app) with:

Demo YFX wallet (fake funds only)

Delivery/ride mock flow

Feature flags (everything else shows Coming Soon)


After feedback is good → flip to public (www.yardflex.app).


3) Make the webpage “installable” as an app (PWA)

Yes—what you saw before is a PWA (Progressive Web App). Users tap “Add to Home Screen” and it behaves like an app (full-screen, icon, offline shell).

Add these three pieces:

A) manifest.json

{
  "name": "YardFlex",
  "short_name": "YardFlex",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#000000",
  "theme_color": "#0b3d2e",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}

B) Link it in your HTML

<link rel="manifest" href="/manifest.json" />
<meta name="theme-color" content="#0b3d2e" />
<meta name="apple-mobile-web-app-capable" content="yes" />
<meta name="apple-mobile-web-app-status-bar-style" content="black" />
<link rel="apple-touch-icon" href="/icons/icon-192.png" />

C) Minimal service worker (/sw.js)

self.addEventListener("install", (e) => {
  e.waitUntil(caches.open("yf-v1").then(c => c.addAll(["/","/index.html","/styles.css"])));
});
self.addEventListener("fetch", (e) => {
  e.respondWith(caches.match(e.request).then(r => r || fetch(e.request)));
});

Register it once in your app:

if ("serviceWorker" in navigator) {
  navigator.serviceWorker.register("/sw.js");
}

Now users can install the webpage like an app. Later you can still ship true native apps (Android/iOS) using the same backend.

4) Do you need to “register” to put the web up?

To host a private/public website: No special government registration is required.

To protect the name/brand: domain + trademark + COJ registration (recommended).

To move real money: company + payment partner + KYC/AML. For the demo, keep fake funds only.


5) Simple test plan (what to verify before public)

1. Wallet (demo funds): top-up sandbox → Send → Request → QR pay → refunds.


2. Orders: create order → mock driver en route → delivered → split 85/15 shows in receipts.


3. Flags: Only Ride / Wallet / Shop live; Rentals / Health / Household show “Coming Soon.”


4. PWA: Add to home screen works on Android + iPhone (Safari iOS supports PWAs).


5. Access: invite codes/magic links work; NDA screen shows once.



6) After web: turning into store apps

Android/iOS wrappers: use Capacitor or React Native to package your web app.

Submit to Google Play (US$25 one-time) and Apple Developer (US$99/year).

Native builds can reuse your web backend and flag system.
