🌍 YaadFlex Global Theme Pack (Overlay Spec)

🎨 Structure

Each country gets:

1. Flag overlay (official flag, SVG/PNG, wave animation option).


2. Color theme (derived directly from flag colors, applied to buttons, borders, glow effects).


3. Background design (subtle cultural texture, pattern, or animation).


4. Team identity name (e.g., YaadFlex Jamaica, YaadFlex Kenya).


5. Optional alternate themes (festival mode, sports mode, night mode).

⚡ Best Way Out (so it works everywhere)

Use vector flags (SVG) → scale sharp on all devices.

Pull colors directly from the flag → apply them consistently (buttons, borders, accents).

Keep backgrounds subtle, semi-transparent → so app text is still readable.

Add 2–3 optional themes per country (festival, heritage, night) for cultural events.

Optimize animations (GPU-friendly, lightweight).
