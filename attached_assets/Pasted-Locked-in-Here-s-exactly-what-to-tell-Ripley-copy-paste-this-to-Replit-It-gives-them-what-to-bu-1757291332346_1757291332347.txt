5) YFX Peg (KWD) — Finance Model (Implement Now)

Invariant: 1 YFX ≡ 1 KWD.

Display formulae:

local_amount = yfx_amount * fx_kwd_to_local

usd_amount   = yfx_amount * fx_kwd_to_usd

jmd_amount   = yfx_amount * fx_kwd_to_jmd


Fare example (Kingston):

Fare (local): 1,200 JMD

If 1 KWD ≈ 500 JMD → yfx = 1200 / 500 = 2.4 YFX

Payouts: Driver = 2.4 * 0.85 = 2.04 YFX; Platform = 0.36 YFX


FX Service (stub now, swappable later):

// fx.ts
export type FxRates = { kwd_to_jmd: number; kwd_to_usd: number; updated_at: string };
export async function getFx(): Promise<FxRates> {
  // TODO: replace with live provider; cache 15 min.
  return { kwd_to_jmd: 500, kwd_to_usd: 3.25, updated_at: new Date().toISOString() };
}
export function yfxToLocal(yfx: number, fx: FxRates, currency: "JMD"|"USD") {
  return currency === "JMD" ? yfx * fx.kwd_to_jmd : yfx * fx.kwd_to_usd;
}

Ledger rule: Store all balances & transactions in YFX; store snapshot FX used per tx for audit.

6) Data Model (MVP)

-- users
id, role("rider"|"driver"|"admin"), name, phone, country_code, created_at

-- wallets
user_id FK, balance_yfx DECIMAL(18,6) DEFAULT 0, updated_at

-- trips
id, rider_id, driver_id, status("created","completed","canceled"),
pickup_text, dropoff_text,
fare_yfx DECIMAL(18,6), fare_local_cents INT, local_currency CHAR(3),
fx_kwd_to_local DECIMAL(12,6), fx_timestamp,
created_at, completed_at

-- payouts
id, driver_id, trip_id, amount_yfx, status("queued","paid","failed"),
schedule("daily"|"weekly"|"fortnightly"|"monthly"),
created_at, paid_at

-- tx_ledger
id, user_id, type("fare_charge","driver_credit","platform_fee"),
amount_yfx, related_trip_id, created_at

-- feature_flags
key TEXT PRIMARY KEY, enabled BOOLEAN, label TEXT, blurb TEXT
