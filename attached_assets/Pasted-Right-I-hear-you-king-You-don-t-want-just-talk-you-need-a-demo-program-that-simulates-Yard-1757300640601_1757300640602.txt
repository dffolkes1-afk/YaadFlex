🛠️ Demo Economic Coding List (Sandbox Mode)

Tables

users(id, name, phone)
wallets(user_id, balance_yfx DECIMAL(18,6))
tx(id, user_id, type ENUM('topup','send','request','spend','earn'), 
   amount_yfx, fx_kwd_to_jmd, fx_kwd_to_usd, created_at, meta JSONB)
orders(id, buyer_id, seller_id, total_yfx, status, created_at)

Endpoints

POST /api/wallet/topup-sandbox   {amount_yfx} 
   -> adds fake funds

POST /api/wallet/send   {to_user_id, amount_yfx, note} 
   -> moves YFX between wallets

POST /api/orders/create {buyer_id, seller_id, total_yfx} 
   -> locks YFX in escrow

POST /api/orders/complete {order_id} 
   -> releases YFX (85% seller, 15% YardFlex)

GET /api/wallet/tx {user_id} 
   -> returns history

Example Transaction

Alice tops up 50 YFX (sandbox)
Alice buys food for 10 YFX
 → Buyer -10
 → Vendor +8.5
 → YardFlex platform +1.5
